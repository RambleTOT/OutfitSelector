# Фото вещей

В этой папке лежат PNG с прозрачным фоном: `{id вещи}.png`, например `i08.png`. Если файл есть, прототип показывает его вместо плоского силуэта (в сетке гардероба, в коллаже образа, в конструкторе).
Чтобы заменить фото, положи PNG с тем же именем. Источники фото и авторы: `CREDITS.md`. Как они были подготовлены: `tools/picks.json`, `tools/cutout.mjs`.
