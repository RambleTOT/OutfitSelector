# Atelier: прототип и MVP

AI-стилист в виде мобильного PWA: человек загружает свои вещи, сервис собирает образы под погоду и повод. Сайт устроен так: лендинг `/`, приложение `/app/`, при первом открытии на телефоне экран «Поставь Atelier на экран», вход по почте с кодом до анкеты (гостевого режима нет). Без `VITE_API_URL` всё работает на моках (демо), с ним включаются настоящий вход, синхронизация, AI и оплата (`server/`). Должно выглядеть и вести себя как настоящее приложение.

## Стек и команды
Vite, React, TypeScript, React Router (HashRouter), zustand + persist (localStorage), framer-motion, без UI-библиотек. Стили через CSS-переменные из `src/styles/tokens.css`.
- `npm run dev` запуск, `npm run build` сборка (tsc + vite), `npm run icons` пересборка иконок из `design_handoff/assets/icons`
- Спецификация продукта: `docs/atelier_mvp_spec.md` (раздел 16 главнее остального текста)
- Дизайн-пакет (только читать): `design_handoff/` (README, screens, components, tokens, animations; макеты в `design/*.dc.html`)
- Прогресс и решения: `PROGRESS.md`. Читать первым в новой сессии
- Сервер: `server/` (Node, без фреймворков, `npm run server:test`), клиентские модули `src/lib/{api,sync,ai,analytics,pwa,config}.ts`, `src/lib/payments/`
- Документы: `docs/DEPLOY.md` (хостинг, домен), `docs/PAYMENTS.md` (CloudPayments), `docs/AI.md` (модели), `docs/MAIL.md` (почта для кодов), `docs/VISION.md` (распознавание вещей, сервис `vision/`), `docs/TIMEWEB.md` и `docs/AGENT_BRIEF.md` (сервер), `docs/AUDIT.md`, юридические черновики `docs/legal/`
- Ссылка `/app/?demo` включает демо-режим (панель справа, без экрана установки), `?demo=0` выключает. Скрипты `tools/audit.mjs`, `tools/record-video.mjs`, `tools/shots.mjs` работают с `?demo`

## Показ
До 500 px приложение на весь экран. Шире: рамка iPhone 390×844 по центру, справа панель демо (только на десктопе): тариф, тема, лимит/оффлайн/подписка закончилась, сброс, пропуск онбординга. Внутри приложения только `position: absolute`, не `fixed`, чтобы шторки и тосты жили внутри рамки.

## Правила
- Цвета, размеры, шрифты только из tokens.css. Названия компонентов и ID экранов как в пакете (OUT-01, WRD-01 и т.д.)
- Тексты интерфейса из макетов слово в слово, по-русски, на «ты», без точек в коротких фразах
- Минимальная ширина 360 px, зоны нажатия от 44 px, текст не меньше 11 px
- Анимации по animations.md, только CSS и framer-motion, без тяжёлых эффектов, учитывать prefers-reduced-motion
- Одно главное действие на экране (градиент `--gradient-sunset-cta`), стекло только на плавающих слоях
- Порядок работы P1…P9 строго по порядку; после каждого пункта: сборка проходит, git commit, обновить PROGRESS.md
- Не задавать лишних вопросов: где пакет молчит, решать разумно и записывать решение в PROGRESS.md
- Тарифы и лимиты: Free 5 образов/нед, 3 фото всего, 3 избранных; Подписка 10/нед, 30 фото/мес, 10 избранных; Подписка+ образы без лимита (до 300 в месяц), 100 фото/мес, избранное без лимита. Шаблоны и конструктор без лимита. Другой вариант тратит лимит, замена вещи нет
