# Каталог красивых фото вещей

Зачем: «Выбрать из шаблона» рисовал вещь силуэтом, это выглядело дёшево. Теперь способ называется «Найти в каталоге»: человек вводит «чёрная футболка оверсайз» и выбирает из готовых студийных фото. Без лимита, как раньше шаблоны.

## Как устроено
- Экран `src/screens/add/Catalog.tsx`, данные и поиск `src/data/photoCatalog.ts`. Поиск по названию, виду, цвету, крою и синонимам («майка», «толстовка», «штаны»), слова совпадают по первым четырём буквам, фильтры «для кого» и «категория».
- Список лежит в `public/catalog/index.json`, картинки в `public/catalog/*.webp` (прозрачный фон, вещь по центру квадрата 768 px). Пока файла нет, показываются 24 встроенных фото демо-гардероба.
- Вещь из каталога сохраняется как обычная (`source: 'catalog'`), поля (материал, крой, тепло, формальность) берутся из записи.

## Откуда берутся картинки
Список позиций (около 200: вид × цвет × крой × для кого) составляет `node tools/catalog/make-list.mjs`, файл `tools/catalog/list.json`. Сборку делает `tools/catalog/build.mjs`: берёт картинку выбранным способом, пропускает через наш сервис распознавания (фон, свет, центровка), проверяет, что вид совпал, и кладёт в `public/catalog/`.

| Способ | Что нужно | Плюсы | Минусы |
|---|---|---|---|
| `--source=generate` (рекомендую) | ключ API генерации изображений (`IMAGE_API_KEY`, `IMAGE_MODEL`, по умолчанию gpt-image-1) | единый студийный стиль, точный цвет и крой, права на картинки наши, 200 фото примерно 8–40 долларов разово | нужен зарубежный сервис и оплата, нужен просмотр результата глазами |
| `--source=pexels` | бесплатный ключ `PEXELS_API_KEY` | бесплатно, лицензия Pexels разрешает коммерческое использование и обработку | качество и единообразие разные, фото с людьми и интерьером приходится отбраковывать, автор сохраняется в `credit` |
| `--source=dir` | свои фото в `tools/catalog/inbox/<id>.jpg` | можно купить готовый пак студийных фото | платно, нужна лицензия на приложение |

Сайты магазинов (Lamoda, Wildberries и т. п.) не парсим: фото защищены авторским правом и условиями сайтов. Законный путь к реальным товарам и фото магазинов, это партнёрские фиды (YML-файлы Admitad, Actionpay и прямые программы магазинов): там разрешён показ карточек товара со ссылкой на магазин. Это следующий этап вместе с рекомендациями «чего не хватает в гардеробе».

Поиск по бирке и штрихкоду для одежды мы не берём: открытых баз по одежде нет, коды привязаны к закрытым базам магазинов.

## Как запустить
```bash
node tools/catalog/make-list.mjs 200
IMAGE_API_KEY=... node tools/catalog/build.mjs --source=generate --vision=http://127.0.0.1:7100 --limit=20   # сначала 20 штук, посмотреть глазами
node tools/catalog/build.mjs --source=generate --vision=http://127.0.0.1:7100                                 # остальные, уже готовые пропускаются
```
Сервис распознавания локально: `cd vision && .venv/bin/uvicorn app.main:app --port 7100`. Отклонённые позиции (вещь не найдена, другой вид) пишутся в `tools/catalog/rejected.json`, их можно собрать повторно.
