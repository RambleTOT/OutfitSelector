# AI в Atelier: что используем и чем заменить

Что умеет серверная часть сейчас и какие модели подключать. Цены и условия я сверял по официальным страницам в ноябре 2026. Всё, что помечено «проверить», надо уточнить в личном кабинете или у менеджера перед запуском: тарифы меняются.

## Три задачи

| Задача | Что нужно от модели | Где в коде |
|---|---|---|
| 1. Подбор образа из вещей пользователя | Текстовая модель, на выходе JSON с id вещей и пояснением. Вход ~700 токенов, выход ~100 | `server/ai/prompt.mjs`, `POST /api/ai/outfit`, клиент `src/lib/ai.ts` |
| 2. Распределение вещи по категориям и «приведение в вид» (вид, цвет, формальность, тепло, крой) по фото | Модель с картинками на входе | `POST /api/ai/describe`, сейчас только OpenAI-совместимые API |
| 3. Вырезание фона | Не языковая модель: сегментация (rembg, BiRefNet) | `POST /api/ai/cutout`, прокси к твоему сервису `CUTOUT_URL` |

Если AI на сервере не настроен или не ответил, клиент использует встроенный алгоритм (`src/data/generate.ts`, на шаблонах образов) и локальное вырезание (`src/lib/image.ts`). Человек образ получит в любом случае, а лимит списывается только за удачный.

## Сравнение для подбора образа (задача 1)

Стоимость образа считаю по ~800 токенов суммарно (подсказка + список до 25 вещей + ответ).

| Вариант | Цена | Данные остаются в РФ | Качество на русском | Риски |
|---|---|---|---|---|
| **GigaChat** (Сбер), Lite / Pro | Для физлиц есть бесплатный пакет: 365 млн токенов на 12 месяцев (250 млн на Lite, 40 млн на Pro). Платно: Lite 20 млн токенов за 1 300 ₽ (~0,05 ₽ за образ), Pro 3 млн за 1 500 ₽ | Да | Хорошее, JSON держит | Один поток на физлицо. Для нового клиента с 1 сентября 2026 оплата идёт через cloud.ru. **Проверить:** можно ли бесплатный пакет использовать в коммерческом продукте (раздел «Коммерческое использование» на developers.sber.ru). Нужен сертификат Минцифры на сервере |
| **YandexGPT Lite** (Yandex AI Studio) | 0,20 ₽ за 1 000 токенов синхронно, то есть ~0,16 ₽ за образ. Грант на старте у новых аккаунтов Yandex Cloud, проверить размер | Да | Хорошее, JSON иногда с обёрткой, мы её срезаем | Нужны каталог и сервисный аккаунт в Yandex Cloud, оплата с юрлица или ИП |
| **cloud.ru Foundation Models** | Каталог открытых моделей (Qwen, DeepSeek и др.) с оплатой за токены, цены на сайте. **Проверить:** совместимость с OpenAI-форматом, тогда подключается через `AI_PROVIDER=openai` без кода | Да | Зависит от модели | Новый сервис, цены и лимиты уточнять |
| **OpenRouter**, бесплатные модели (`...:free`) | 0 ₽, но лимиты по запросам в день и в минуту, модели меняются | Нет (сервера за границей) | Среднее | Не для продакшена: лимиты, пропадающие модели. В подсказке нет личных данных, только названия вещей, поэтому для беты юридически допустимо, но не надёжно |
| **DeepSeek / Qwen API напрямую** | Очень дёшево (доли копейки за образ) | Нет | Хорошее | Доступность из РФ и оплата иностранной картой. Только для беты и экспериментов |
| **Ollama на своём сервере** (Qwen2.5 7B и подобные) | 0 ₽ за запросы, но нужен сервер от 8 ГБ памяти (≈1 500–3 000 ₽ в месяц) и на CPU ответ идёт 15–40 секунд | Да | Среднее на 7B | Медленно, пока нет видеокарты |
| **Встроенный алгоритм** (сейчас) | 0 ₽ | Да | Образы по шаблонам, без «понимания» повода и пожелания | Остаётся как запасной вариант всегда |

**Мой выбор для MVP.** Бета: GigaChat на бесплатном пакете (после проверки условий коммерческого использования), запасной вариант: встроенный алгоритм. Когда пойдут платные пользователи: YandexGPT Lite или платный GigaChat Lite. Экономика не страшная: подписка 300 ₽ даёт максимум 10 образов в неделю, то есть ~43 в месяц, это 2–7 ₽ на модель. Подписка+ ограничена 300 образами в месяц: максимум ~50 ₽ на модель при выручке 600 ₽.

Бесплатные «открытые без ключа» API для продакшена я не рекомендую. Я их пробовал: Pollinations отдаёт одну генерацию в 45 секунд и потом ошибку по лимиту, годится только для разовой проверки.

## Как подключить (задача 1)

1. Получить ключ.
   - **GigaChat:** [developers.sber.ru/studio](https://developers.sber.ru/studio) → создать проект GigaChat API → «Получить ключ». Нужен «Ключ авторизации» (строка в base64). Scope для физлица `GIGACHAT_API_PERS`.
   - **Yandex:** в Yandex Cloud создать каталог, сервисный аккаунт с ролью `ai.languageModels.user`, выпустить API-ключ. Каталог берётся из консоли.
   - **OpenAI-совместимый:** `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`.
2. В `server/.env` указать `AI_PROVIDER=gigachat` (или `yandex`, `openai`) и ключи (см. `server/.env.example`).
3. Для GigaChat на сервере нужен корневой сертификат Минцифры, иначе запрос к `ngw.devices.sberbank.ru` упадёт с ошибкой сертификата. Скачать сертификат на странице GigaChat «Установка сертификатов НУЦ Минцифры», положить в `/opt/atelier/russian_trusted_root_ca.pem` и раскомментировать `NODE_EXTRA_CA_CERTS` в `deploy/atelier-api.service`.
4. Перезапустить: `sudo systemctl restart atelier-api`. Проверка: `curl https://твой-домен/api/config` покажет `"ai": true`.
5. В приложении войти и собрать образ. Если AI ответил плохо или недоступен, человек получит образ из встроенного алгоритма.

Правила, которые защищают от «выдумок» модели, уже в коде (`parseOutfit`): берутся только настоящие id вещей, обязателен верх+низ или платье, нельзя две вещи одной категории, платье не сочетается с верхом и низом. Ответ не прошёл проверку: одна повторная попытка, потом запасной алгоритм без списания лимита.

## Описание вещи по фото (задача 2)

Сейчас работает через OpenAI-совместимый API с картинками: `AI_PROVIDER=openai`, `OPENAI_VISION_MODEL=<модель с vision>`. Сервер отдаёт JSON с видом, цветом, формальностью, теплом, кроем, рисунком и материалом, а также признак «это не одежда» (тогда показывается экран «Это не одежда» и лимит не тратится).

GigaChat и Yandex тоже принимают картинки, но по-другому: GigaChat через загрузку файла (`/files`) и поле `attachments`, Yandex через отдельные модели. Это пока не подключено: нужен ещё один адаптер в `server/ai/providers.mjs` по образцу существующих (около 30 строк). Без него карточку заполняет клиент по цвету картинки и подсказке из названия файла, пользователь правит её на экране карточки.

## Вырезание фона (задача 3)

Не язык, а сегментация. Что можно взять:

| Вариант | Цена | Заметки |
|---|---|---|
| **rembg** (Python, модели u2net, isnet) на своём сервере | 0 ₽ | Лёгкий, ~1–3 с на CPU, качество хорошее на вещах на ровном фоне |
| **BiRefNet** (лицензия MIT) | 0 ₽ | Качество лучше, но тяжелее: на CPU 5–15 с, лучше с видеокартой |
| Облачные API (remove.bg и подобные) | платно, за границей | Фото уходят за рубеж, это нарушает 152-ФЗ, если на фото есть люди. Не брать |
| В браузере (WASM) | 0 ₽ | Фото не покидают телефон, но нужны 40–200 МБ модели и мощный телефон. Библиотека `@imgly/background-removal` под AGPL, для закрытого коммерческого продукта нужна платная лицензия. Не брал |

Самое простое для MVP: контейнер rembg рядом с API.

```bash
docker run -d --restart=always --name rembg -p 127.0.0.1:7000:7000 danielgatis/rembg s --host 0.0.0.0 --port 7000
```

В `server/.env`: `CUTOUT_URL=http://127.0.0.1:7000/api/remove`. Проверь формат запроса в README образа: сервер шлёт форму с полем `file`. Если у твоей версии поле другое, поменяй в `server/app.mjs` (маршрут `/api/ai/cutout`).

Пока `CUTOUT_URL` пуст, фон вырезается на телефоне встроенным способом (`src/lib/image.ts`), он хорош на вещах на светлом ровном фоне.

## 152-ФЗ в двух строках

В модель уходят только названия и свойства вещей, повод и пожелание. Почты и имени там нет. Фото уходят только на твой сервер и (по желанию) на vision-модель в РФ. Оригинал фото после обработки удаляется (так написано в политике конфиденциальности). Если подключишь зарубежную модель, пересмотри политику.
