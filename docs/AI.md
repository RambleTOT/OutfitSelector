# AI в Atelier: что используем и чем заменить

Что умеет серверная часть сейчас и какие модели подключать. Цены и условия я сверял по официальным страницам в ноябре 2026. Всё, что помечено «проверить», надо уточнить в личном кабинете или у менеджера перед запуском: тарифы меняются.

## Две задачи

| Задача | Что нужно от модели | Где в коде |
|---|---|---|
| 1. Подбор образа из вещей пользователя | Текстовая модель, на выходе JSON с id вещей и пояснением. Вход ~700 токенов, выход ~100 | `server/ai/prompt.mjs`, `POST /api/ai/outfit`, клиент `src/lib/ai.ts` |
| 2. Поиск вещей на фото, вырезание фона, вид и цвет | Не языковая модель, а модели компьютерного зрения на нашем сервере (SegFormer, silueta, FashionSigLIP) | `vision/`, `POST /api/ai/analyze`, подробно в `docs/VISION.md` |

Если AI на сервере не настроен или не ответил, клиент использует встроенный алгоритм (`src/data/generate.ts`, на шаблонах образов) и локальное вырезание (`src/lib/image.ts`). Человек образ получит в любом случае, а лимит списывается только за удачный.

## Сравнение для подбора образа (задача 1)

Стоимость образа считаю по ~800 токенов суммарно (подсказка + список до 25 вещей + ответ).

Платно: Lite 20 млн токенов за 1 300 ₽ (~0,05 ₽ за образ), Pro 3 млн за 1 500 ₽ | Да | Хорошее, JSON держит | Один поток на физлицо. **Мой выбор для MVP.** Бета: модель класса Flash/Plus (Qwen, DeepSeek) через любого российского провайдера с OpenAI-совместимым API, выбранная по результатам `npm run ai:eval` (см. ниже), запасной вариант: встроенный алгоритм. GigaChat на бесплатном пакете в продукте использовать нельзя. Когда пойдут платные пользователи: YandexGPT Lite или платный GigaChat Lite. Экономика не страшная: подписка 300 ₽ даёт максимум 10 образов в неделю, то есть ~43 в месяц, это 2–7 ₽ на модель. Подписка+ ограничена 300 образами в месяц: максимум ~50 ₽ на модель при выручке 600 ₽.

Бесплатные «открытые без ключа» API для продакшена я не рекомендую. Я их пробовал: Pollinations отдаёт одну генерацию в 45 секунд и потом ошибку по лимиту, годится только для разовой проверки.

## Как подключить (задача 1)

1. Получить ключ.
   - **GigaChat:** [developers.sber.ru/studio](https://developers.sber.ru/studio) → создать проект GigaChat API → «Получить ключ». Нужен «Ключ авторизации» (строка в base64). Scope для физлица `GIGACHAT_API_PERS`.
   - **Yandex:** в Yandex Cloud создать каталог, сервисный аккаунт с ролью `ai.languageModels.user`, выпустить API-ключ. Каталог берётся из консоли.
   - **OpenAI-совместимый:** `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`.
2. В `server/.env` указать `AI_PROVIDER=gigachat` (или `yandex`, `openai`) и ключи (см. `server/.env.example`).
3. Для GigaChat на сервере нужен корневой сертификат Минцифры, иначе запрос к `ngw.devices.sberbank.ru` упадёт с ошибкой сертификата. Скачать сертификат на странице GigaChat «Установка сертификатов НУЦ Минцифры», положить в `/opt/atelier/russian_trusted_root_ca.pem` и раскомментировать `NODE_EXTRA_CA_CERTS` в `deploy/atelier-api.service`.
4. Перезапустить: `sudo systemctl restart atelier-api`. Проверка: `curl https://твой-домен/api/config` покажет `"ai": true`.
5. В приложении войти и собрать образ. Если AI ответил плохо или недоступен, человек получит образ из встроенного алгоритма.

Правила, которые защищают от «выдумок» модели, уже в коде (`parseOutfit`): берутся только настоящие id вещей, обязателен верх+низ или платье, нельзя две вещи одной категории, платье не сочетается с верхом и низом. Ответ не прошёл проверку: одна повторная попытка, потом запасной алгоритм без списания лимита.

## Распознавание вещей и вырезание фона (задача 2)

Это отдельная подсистема, и **языковые модели (GigaChat, Yandex) в ней не участвуют**. Фото обрабатывает наш сервис `vision/` на нашем сервере: он находит вещи (на человеке и отдельно), вырезает их с фона, определяет вид, цвет и рисунок. Архитектура, модели, замеры скорости, лицензии, ограничения и запуск: `docs/VISION.md`.

## 152-ФЗ в двух строках

В модель уходят только названия и свойства вещей, повод и пожелание. Почты и имени там нет. Фото уходят только на твой сервер (сервис `vision/`), нигде не сохраняются в исходном виде и никуда дальше не передаются. Оригинал фото после обработки удаляется (так написано в политике конфиденциальности). Если подключишь зарубежную модель, пересмотри политику.

## Как выбрать модель по данным, а не на глаз

Задача простая и без памяти: каждый запрос самодостаточен (системный промпт ~250 токенов, до 25 вещей по ~25 токенов, ответ ~60 токенов), модель ничего не «хранит» между запросами, весь гардероб приходит в запросе. Важны не размер контекста, а три вещи: строго держать JSON, соблюдать запреты (не носит, «не хочу джинсы», нельзя две вещи одной категории) и не ошибаться с погодой и поводом.

Проверка на настоящей задаче: `tools/ai-eval.mjs` берёт боевой промпт и боевую проверку ответа (`server/ai/prompt.mjs`), гоняет 48 случаев и считает долю верных образов, скорость и цену.

```bash
EVAL_BASE_URL=https://.../v1 EVAL_KEY=... EVAL_MODEL=имя-модели \
EVAL_PRICE_IN=4 EVAL_PRICE_OUT=17 npm run ai:eval        # цены в рублях за 1 млн токенов
EVAL_MOCK=good npm run ai:eval                           # проверка самого стенда без ключа
```

Дополнительно: `EVAL_TEMP=0.3` (в проде 0.7), `EVAL_JSON=1` (просить JSON-режим), `EVAL_N`, `EVAL_USERS`, `EVAL_OUTFITS`. Ключ только в переменной окружения, в вывод не попадает. Результаты в `.ai-eval/` (в git не идёт).

**Правило выбора:** берём самую дешёвую модель, у которой «верно с учётом одного повтора» не ниже 95%, p95 по скорости до 8 секунд, а ошибки не в запретах пользователя. Всё остальное закрывает запасной алгоритм.

**Экономика (800 токенов на вход и 100 на выход на образ, подписка 43 образа в месяц, Подписка+ до 300):**

| Класс цены, ₽ за 1 млн (вход / выход) | Образ | Подписка в месяц | Подписка+ в месяц |
|---|---|---|---|
| Flash, 4 / 17 | 0,005 ₽ | 0,2 ₽ | 1,5 ₽ |
| Flash, 12 / 23 | 0,012 ₽ | 0,5 ₽ | 3,6 ₽ |
| Среднее по cloud.ru, 35 / 70 | 0,035 ₽ | 1,5 ₽ | 10,5 ₽ |
| YandexGPT Lite, 200 / 200 | 0,18 ₽ | 7,7 ₽ | 54 ₽ |
| YandexGPT Pro, 1 200 / 1 200 | 1,08 ₽ | 46 ₽ | 324 ₽ |

Вывод: класс Flash и Lite экономику не трогает. Класс Pro на Подписке+ съедает половину выручки (600 ₽), его брать не нужно. Цены из обзоров, перед платежом сверь в кабинете.
