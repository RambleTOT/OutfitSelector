# Согласие на обработку персональных данных

Редакция от {{ДАТА}}.

Физическое лицо (далее — «Пользователь»), входя в сервис Atelier ({{САЙТ}}, далее — «Сайт») и отмечая поле «Даю согласие на обработку персональных данных», свободно, своей волей и в своём интересе, а также подтверждая свою дееспособность, предоставляет {{ИСПОЛНИТЕЛЬ}}, ИНН {{ИНН}}, самозанятому, адрес: {{АДРЕС}}, электронная почта {{ПОЧТА ПОДДЕРЖКИ}}, телефон {{ТЕЛЕФОН}}, Telegram {{ТЕЛЕГРАМ}} (далее — «Оператор»), согласие на обработку персональных данных (далее — «Согласие») на следующих условиях.

## 1. Способ обработки

Согласие предоставляется для обработки персональных данных как без использования средств автоматизации, так и с их использованием.

## 2. Какие данные

- адрес электронной почты — для регистрации, входа по коду, отправки служебных писем (код входа, сведения об оплате, ответы поддержки);
- имя, город, рост, размер, ответы анкеты стиля — для подбора образов (необязательные поля Пользователь заполняет по своему желанию);
- фотографии вещей и сведения о вещах: название, категория, цвет, материал и другие характеристики — для ведения гардероба и подбора образов;
- приблизительная геопозиция, только если Пользователь разрешил её определить: координаты округляются, используются для прогноза погоды и Оператором не сохраняются;
- сообщения в поддержку — для ответов на обращения;
- сведения о выбранном тарифе, сроке его действия и платежах (номер банковской карты Оператору не передаётся, его принимает платёжный сервис);
- технические данные: IP-адрес, тип устройства и браузера, действия в сервисе, файлы cookie, дата и версия настоящего Согласия — для работы сервиса, статистики и подтверждения того, что Согласие получено.

## 3. Цели

Создание и ведение аккаунта, вход по коду из письма, подбор образов, определение погоды, приём оплаты и предоставление платного тарифа, ответы в поддержке, отправка напоминаний (только если Пользователь их включил), улучшение сервиса на основе обезличенной статистики, формирование доказательств на случай спора, исполнение требований законодательства.

## 4. Действия с данными

Сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передача лицам, которым Оператор поручил обработку (раздел 5), обезличивание, блокирование, удаление, уничтожение.

## 5. Кому поручена обработка

Оператор вправе поручить обработку лицам, которые действуют по его заданию и только в объёме, необходимом для целей выше:

- хостинг-провайдер {{ХОСТИНГ}}: хранение данных на серверах в Российской Федерации;
- почтовый сервис Рег.ру: отправка кодов входа и служебных писем на почту Пользователя;
- платёжный сервис Robokassa: приём платежей, передаются данные, нужные для платежа и чека (почта);
- {{AI-ПРОВАЙДЕР}}: подбор образов по описаниям вещей и пожеланиям Пользователя, без почты и имени;
- Яндекс.Метрика: обезличенная статистика посещений.

Базы данных с персональными данными находятся на территории Российской Федерации. Данные не продаются и не передаются для рекламы. Для прогноза погоды сервер Оператора обращается к внешнему сервису с округлённой точкой на карте, без почты, имени и иных данных Пользователя.

## 6. Срок действия

Согласие действует со дня его предоставления до момента прекращения обработки персональных данных: до удаления аккаунта или отзыва Согласия.

## 7. Как отозвать Согласие

Согласие можно отозвать в любой момент:

- удалить аккаунт в приложении (Профиль → Удалить аккаунт);
- написать в поддержку в приложении (Профиль → Поддержка);
- направить заявление в свободной форме на электронную почту {{ПОЧТА ПОДДЕРЖКИ}} или по адресу: {{АДРЕС}}.

Оператор прекращает обработку и уничтожает данные в течение 30 дней с получения отзыва. В случае отзыва Оператор вправе продолжить обработку без Согласия при наличии законных оснований, например хранить сведения о платежах, которые он обязан хранить по закону. После отзыва Согласия пользоваться сервисом нельзя: без этих данных он не работает.

## 8. Как Согласие даётся

Пользователь отмечает поле «Даю согласие на обработку персональных данных» на экране входа в приложение. Отметка по умолчанию снята и ставится самим Пользователем. Оператор сохраняет дату и версию Согласия, чтобы подтвердить, что оно получено.

Подробности об обработке данных — в Политике конфиденциальности и обработки персональных данных: {{САЙТ}}/legal/privacy.html.
