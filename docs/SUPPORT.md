# Поддержка внутри приложения (без почты)

Экран «Профиль → Поддержка» (`/app/#/support`): человек пишет сообщение, оно хранится на сервере, ответ команды появляется в том же экране (обновляется раз в 15 секунд, в Профиле рядом со строкой видно «Ответили: N»). Кнопки «Написать в поддержку» на экранах месячного лимита и ошибки оплаты ведут туда же с темой.

## Как отвечать
Нужен токен администратора: один раз добавь в `/opt/atelier/server/.env` строку `SUPPORT_ADMIN_TOKEN=<длинная случайная строка>` (`openssl rand -hex 24`) и перезапусти API (`sudo systemctl restart atelier-api`). На сервере:
```bash
set -a; . /opt/atelier/server/.env; set +a
node /opt/atelier/server/support-cli.mjs list                         # кто ждёт ответа
node /opt/atelier/server/support-cli.mjs show почта@пример.ру         # вся переписка
node /opt/atelier/server/support-cli.mjs reply почта@пример.ру "Починили, обнови приложение"
```
Новые сообщения видно сразу в журнале: `journalctl -u atelier-api -f | grep support`.

## Уведомление в Telegram (по желанию)
Создай бота у @BotFather, напиши ему любое сообщение, возьми свой chat id (например через @userinfobot) и добавь в `.env`: `SUPPORT_TG_BOT_TOKEN=...` и `SUPPORT_TG_CHAT_ID=...`. Тогда каждое сообщение придёт тебе в Telegram вместе с готовой командой для ответа. Если задать `VITE_SUPPORT_TG` (ник без @) при сборке, на экране появится ещё и ссылка «Или написать в Telegram».

## Что хранится
Только текст сообщений и время. Переписка удаляется вместе с аккаунтом. Лимит: 10 сообщений в час от одного человека, до 1500 символов.
